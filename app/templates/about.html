Project Overview

Depression Detection from Social Media using Hybrid Transformer Models is a final year academic project developed to identify possible signs of depression from social media text using NLP and transformer-based analysis.

The system is designed to analyze user-entered text and present prediction results, confidence score, risk level, and helpful visual insights through a web interface.

How It Works

The user enters text, and the system processes it using transformer-based methods to detect emotional patterns. After analysis, the application displays useful prediction outputs and graphical representations.

Key Features

  • Depression risk prediction
  • Confidence score visualization
  • Risk level indication
  • Attention-based word highlighting
  • ROC curve and confusion matrix display

Project Goal

This project demonstrates how deep learning and NLP can be applied to mental health related text analysis in a research-oriented and user-friendly way.
